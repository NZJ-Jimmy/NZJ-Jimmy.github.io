## 关于本站

本站源码位于 `main` 分支，由 GitHub Actions 自动构建并发布到 `gh-pages` 分支。

GNU/Linux 专栏不是复制到本站的一份快照，而是通过 **Git submodule** 引用
[E-Vertin/GNU-Linux-Guides](https://github.com/E-Vertin/GNU-Linux-Guides)，
在统一的 MkDocs 导航和搜索中展示。
