3. 考虑集合 $A$ 和 $B$，请证明以下有关对称差的性质：

(1) $A \oplus B \subseteq A \cup B$

解：

$$\because A \oplus B = (A-B) \cup (B-A) \ $$

  1. 若$x \in (A-B)$，有
    $$\begin{gathered}A-B \subseteq A \subseteq A\cup B \\therefore x \in A\cup B\end{gathered}$$
  2. 若 $x \in (B-A)$ ，有
    $$\begin{gathered}B-A \subseteq B \subseteq A \cup B \\therefore x \in A\cup B\end{gathered}$$
    所以, $A \oplus B \subseteq A \cup B$
(2) $(A \oplus B) \cap (A \cap B) = \emptyset$

解：

$$\because A \oplus B = (A-B) \cup (B-A)$$

  1. 若$x \in (A-B)$，则
    $$\begin{gathered}A-B = A - A\cap B \\therefore x \notin A \cap B\end{gathered}$$
  2. 若$x \in (B-A)$，则
    $$\begin{gathered}B-A = B-A\cap B \\therefore x \notin A \cap B\end{gathered}$$
    所以, $(A \oplus B) \cap (A \cap B) = \emptyset$
(3) $A \oplus B = (A \cup B) - (A \cap B)$

解：

$$\begin{aligned}(A \cup B) - (A \cap B) &= (A \cup B) \cap (\overline{A \cap B}) \&= (A \cup B) \cap (\bar{A} \cup \bar{B}) \&= A \cap \bar{B} \cup \bar{A} \cap B \&= (A - B) \cup (B - A) \&= A \oplus B\end{aligned}$$
证得$A \oplus B = (A \cup B) - (A \cap B)$

4. 考虑集合$A, B, C$，如果$A \oplus C = B \oplus C$，请证明$A = B$。

证：

假设$A\neq B$，存在有$x\in A$且$x\notin B$
设此$x \in C$，又$\because x\in B \implies x\in (C-B) \subseteq B\oplus C$
同时，$x\in A\implies x\notin A \oplus C$
存在$x\in B\oplus C$且$x\notin A \oplus C$
但$A \oplus C = B \oplus C$，说明假设$A\neq B$不成立
所以$A=B$

5. 对称差运算是否满足下面的运算律？如果满足，请给出证明；如果不满足，请给出一个反例：

(1) 交换律

满足交换律，
证：
$$\begin{aligned}A \oplus B &= (A - B) \cup (B - A) \&= (B - A) \cup (A - B) \&= B \oplus A\end{aligned}$$
因此，$A \oplus B = B \oplus A$，满足交换律

(2) 结合律

满足结合律，
证：
$$\begin{aligned}(A \oplus B) \oplus C&=\left\lbrace\left[\left(A-B\right)\cup\left(B-A\right)\right]-C\right\rbrace\cup\left\lbrace C-[\left(A-B\right)\cup\left(B-A\right)]\right\rbrace \&=\left[\left(A\cap\overline{B}\right)\cup\left(B\cap\overline{A}\right)\cap\overline{C}\right]\cup\left[C\cap\overline{\left(A\cap\overline{B}\cup B\cap\overline{A}\right)}\right] \&=[(A\cap\ \overline{B} \cap\ \overline{C} )\ \ \cup(\overline{A} \cap\ B\cap\ \overline{C} )]\cup[C\cap((\overline{A} \cup B )\cap(\overline{B} \cup A )]\&=(A\cap\ \overline{B} \cap \overline{C})\cup(\overline{A} \cap\ \overline{B} \cap\ \overline{C})\cup(\overline{A}\cap\ \overline{B}\cap\ C)\cup(A\cap\ B\cap\ C)\A \oplus (B\oplus C)&=\left{A-\left[\left(B-C\right)\cup\left(C-B\right)\right]\right}\cup\left{\left[\left(B-C\right)\cup\left(C-B\right)\right]-A\right} \&=\left(A\cap\overline{B\cap\overline{C}\cup C\cap\overline{B}}\right)\cup\left[\left(B\cap\overline{C}\cup C\cap\overline{B}\right)\cap\overline{A}\right]\&=\left[A\cap\left(\overline{B}\cup C\right)\cap\left(\overline{C}\cup B\right)\right]\cup\left[\left(\overline{A}\cap B\cap\overline{C}\right)\cup\left(\overline{A}\cap\overline{B}\cap C\right)\right] \&=\left(A\cap\overline{B}\cap\overline{C}\right)\cup\left(A\cap B\cap C\right)\cup\left(\overline{A}\cap B\cap\overline{C}\right)\cup\left(\overline{A}\cap\overline{B}\cap C\right)\end{aligned}$$
所以，$(A\oplus B)\oplus C = A \oplus (B \oplus C)$

(3) $\cap$对$\oplus$的分配律

满足 $\cap$对$\oplus$的分配律
证明$(A\oplus B)\cap C=(A\cap C)\oplus (B\cap C)$：
$$\begin{aligned}&(A\cap \bar B \cup \bar A \cap B)\cap C \=& A\cap \bar B \cap C \cup \bar A \cap B\cap C\end{aligned}$$
$$\begin{aligned}&(A\cap C)\oplus( B\cap C)\=& (A\cap C-B\cap C)\cup (B\cap C-A\cap C) \=& \left(A\cap C\cap \overline{B\cap C}\right) \cup \left(B\cap C\cap \overline{A\cap C}\right) \=& \left[A\cap C \cap \left(\bar B \cup \bar C\right)\right] \cup \left[B\cap C \cap \left(\bar A \cup \bar C \right) \right] \=& A \cap \bar B \cap C \cup \bar A\cap B\cap C\end{aligned}$$

(4) $\oplus$对$\cap$的分配律

不满足$(A\cap B)\oplus C = (A\oplus B)\cap (A\oplus C)$，反例：

设$\begin{cases}A=\left{ 1 \right} \ B=\left{ 2 \right} \ C=\left{ 3 \right}\end{cases}$，则：
$$\begin{aligned}(A\cap B)\oplus C=\left(\emptyset -\left{ 3 \right} \right)\cup \left(\left{ 3 \right}-\emptyset \right) &= \left{ 3 \right} \(A\oplus B)\cap (A\oplus C) =\left{ 1,2 \right} \cap \left{1,3 \right} \ &=\left{ 1 \right} \end{aligned}$$

所以，$(A\cap B)\oplus C \not= (A\oplus B)\cap (A\oplus C)$
